## الفيديو التعريفي
ينتهي الفيديو التعريفي داخل المحاكي بباركود رابط المحاكي، ويمكن تحميله ملفًا من زر ⬇ (أو مشاركته مباشرة من الجوال) لإرساله إلى المتدربين: [video/motor-lab-intro.mp4](video/motor-lab-intro.mp4).
بعد أي تعديل على مشاهد الفيديو أو تسجيلات `audio/` أعد إنشاء الملف بالأمر: `node tools/make-intro-video.mjs` (يحتاج Playwright وffmpeg).

## مقاطع توصيل التمارين
في نافذة «▶ مقطع التوصيل» زر **⬇ تحميل** يحمّل مقطع شرح التمرين المختار كاملًا ملف فيديو (التوصيل سلكًا سلكًا ثم تجربة التشغيل، مع الشرح المكتوب والصوتي) من [video/clips/](video/clips/)، لمشاهدته دون المحاكي أو إرساله إلى المتدربين.
بعد أي تعديل على التوصيلات النموذجية أو نصوص الشرح أو تجربة التشغيل أعد إنشاء الملفات بالأمر: `node tools/make-clip-videos.mjs` (أو لتمارين محددة: `node tools/make-clip-videos.mjs p1 p7`). يحتاج Playwright وffmpeg وأداة edge-tts (`pip install edge-tts`)، واتصالًا بالإنترنت يصل إلى `speech.platform.bing.com` للصوت الرجالي «حامد».
تصنع الأداة نفسها أيضًا جمل الشرح بصوت «حامد» ملفاتٍ في `audio/v/`، فيشغّلها «🌐 الصوت عبر الإنترنت» داخل المحاكي بصوت رجالي، ومعها شرح المقطع العرضي في حالات تجربة التشغيل، وما ليس له ملف يُنطق بصوت Google. لصنع ملفات الصوت وحدها دون الفيديو: `node tools/make-clip-videos.mjs --voice`.
