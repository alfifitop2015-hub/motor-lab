## الفيديو التعريفي
ينتهي الفيديو التعريفي داخل المحاكي بباركود رابط المحاكي، ويمكن تحميله ملفًا من زر ⬇ (أو مشاركته مباشرة من الجوال) لإرساله إلى المتدربين: [video/motor-lab-intro.mp4](video/motor-lab-intro.mp4).
بعد أي تعديل على مشاهد الفيديو أو تسجيلات `audio/` أعد إنشاء الملف بالأمر: `node tools/make-intro-video.mjs` (يحتاج Playwright وffmpeg).
